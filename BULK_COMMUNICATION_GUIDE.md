# Bulk Communication System - User Guide

## 🎯 **How to Use the Bulk Communication System**

### **Step 1: Access the System**
1. **Login** to your admin account at `admin@linkzup.com`
2. **Navigate** to Admin Dashboard → **Bulk Communication**

### **Step 2: View User Categories**
The system automatically categorizes users into 3 types:

#### **📅 Trial Users (9 users)**
- Users with active 2-day trial period
- Have `isTrialActive: true`
- Currently have 9 trial users in your database

#### **✅ Active Users (8 users)**  
- Users with active subscriptions
- Have `subscriptionStatus: "active"`
- Currently have 8 active users

#### **⏳ Pending Users (0 users)**
- Users with expired trials or no active subscription
- Need to activate their subscription

### **Step 3: Select Users**
1. **Choose** a user category tab (Trial/Active/Pending)
2. **Search** users by name, email, mobile, or city
3. **Select** individual users or click "Select All"
4. **View** selected count in the "Compose Message" button

### **Step 4: Compose Message**
1. **Click** "Compose Message" button
2. **Choose** message type:
   - **Email**: Sent as in-app notifications
   - **WhatsApp**: Ready for WhatsApp integration
3. **Use** pre-built templates or write custom content
4. **Preview** recipients before sending

### **Step 5: Send Messages**
1. **Fill** in subject and content
2. **Click** "Send Message"
3. **Track** delivery status in real-time
4. **View** results and any failures

## 🔧 **Troubleshooting**

### **If Users Don't Show Up:**
1. **Check** if you're logged in as admin
2. **Refresh** the page
3. **Verify** database connection
4. **Check** browser console for errors

### **If Messages Don't Send:**
1. **Verify** you have selected users
2. **Check** subject and content are filled
3. **Ensure** you have admin permissions
4. **Check** network connection
