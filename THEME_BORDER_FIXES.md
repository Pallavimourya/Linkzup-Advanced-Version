## 🎯 **Border Classes Applied:**

### **Standard Border Classes:**
```css
border-2 border-gray-300 dark:border-gray-600
```

### **Focus State Classes:**
```css
focus:border-teal-500 dark:focus:border-teal-400
```

### **Hover State Classes:**
```css
hover:border-gray-400 dark:hover:border-gray-500
```

### **Checked State Classes (Checkboxes):**
```css
data-[state=checked]:border-teal-500 dark:data-[state=checked]:border-teal-400
```

## 🌓 **Theme Support:**

### **Light Theme:**
- **Borders**: Gray-300 (visible gray borders)
- **Focus**: Teal-500 (teal focus state)
- **Hover**: Gray-400 (darker gray on hover)

### **Dark Theme:**
- **Borders**: Gray-600 (visible gray borders)
- **Focus**: Teal-400 (lighter teal focus state)
