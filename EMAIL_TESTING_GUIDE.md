## 🧪 **How to Test Email Functionality:**

### **Step 1: Test Gmail Configuration**
1. **Go to** Admin → Bulk Communication
2. **Find** the "Test Email Configuration" section (blue card)
3. **Enter** your email address (e.g., `pallavimourya99@gmail.com`)
4. **Click** "Send Test Email"
5. **Check** your Gmail inbox for the test email

### **Step 2: Test Bulk Email**
1. **Select** any user category (Trial/Active/Pending)
2. **Choose** 1-2 users to test with
3. **Click** "Compose Message"
4. **Select** "Email" type
5. **Write** a test message
6. **Send** the message
7. **Check** the recipients' Gmail inboxes

## 🔧 **Troubleshooting:**

### **If Test Email Fails:**
1. **Check** Gmail credentials in environment variables
2. **Verify** Gmail App Password is correct
3. **Check** server logs for error details
4. **Ensure** Gmail SMTP is enabled

### **If Bulk Emails Don't Reach Gmail:**
1. **Test** with the test email feature first
2. **Check** spam/junk folders
3. **Verify** recipient email addresses are correct
4. **Check** delivery status in message history
